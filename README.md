# Интерпретатор арифметических выражений

Проект реализует модель предметной области «арифметическое выражение» и консольное приложение,
демонстрирующее операции базового уровня.

## Возможности

- Разбор строки методом рекурсивного спуска.
- Вычисление выражений:
    - `+`, `-`, `*`, `/`;
    - скобки;
    - унарный минус и унарный плюс;
    - возведение в степень `^`;
    - функции `min`, `max`, `abs`;
    - переменные из контекста.
- Собственные исключения:
    - `ExpressionParseException` — ошибка разбора, содержит позицию в строке;
    - `DivisionByZeroException` — деление на ноль;
    - `UnknownVariableException` — неизвестная переменная;
    - `EvaluationException` — прочие ошибки вычисления.
- Целочисленная модель на `long`.
- JUnit 5 тесты.
